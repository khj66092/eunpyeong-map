카카오맵을 불러오지 못했습니다

· PC에서는 지도열기.bat으로 열어 주세요(주소: http://localhost:8080). index.html을 파일로 직접 열면 카카오맵이 열리지 않습니다.
· 웹에 올렸다면, 카카오 개발자 콘솔 → 앱 → 플랫폼 키 → JavaScript 키 → JavaScript SDK 도메인에 올린 주소(예: https://내사이트.netlify.app)를 등록해야 합니다.
· 다른 카카오 JavaScript 키를 쓰려면 아래에 넣어 주세요.

    자료 출처
    실거래: 국토교통부 실거래가 공개시스템 (2021.1~2026.10.19 계약, 해제 건 제외 · 21~25평=전용 50~64㎡, 31~36평=전용 76~90㎡). 순위는 지도에 표시된 단지끼리 비교한 값이며 2026년 9~10월 계약분은 신고가 덜 들어왔습니다.
    상권·학원가: 소상공인시장진흥공단 상가(상권)정보(2026년 6월)를 직접 집계 — 상권은 약 50m 칸당 점포 5곳 이상, 학원가는 약 100m 칸당 학원(입시·외국어·예체능·컴퓨터) 3곳 이상이 이어진 구역을 둥글게 그린 것입니다.
    정비사업: 구역 경계는 서울도시공간포털 정비구역 고시 도면, 사업 단계는 서울시 정비사업 정보몽땅. 경계가 없는 사업장은 대표 지번 근처의 대략 위치(점)로 표시했습니다.
